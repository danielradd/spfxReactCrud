# spfxReactCrud

CRUD de itens de lista do SharePoint com SPFx e React.

O projeto está em [`spfxReactCRUD/`](spfxReactCRUD/). Veja o [README do projeto](spfxReactCRUD/README.md) para os pré-requisitos (Node 22), como rodar e como fazer o deploy.

**Versão atual:** SPFx 1.24.2 · React 18 · Fluent UI v8 · Heft
